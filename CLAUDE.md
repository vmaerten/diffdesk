# Changelog

Every user-facing change adds its entry to `CHANGELOG.md` under `## Unreleased`, in the same PR — never left for the release. Use the headings and order from `docs/releases.md`, write one line per entry from the user's point of view, and end it with the PR link. Tests and tooling go under `### 🔧 Internal`; changes invisible to users and maintainers need no entry. At release, `## Unreleased` becomes `## X.Y.Z`.
